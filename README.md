<summary>給維護者：如何新增內容</summary>

- 每一頁就是一個 `.md` 檔，用 Markdown 撰寫，推送後即更新。
- 頁與頁之間用**相對連結**串接，例如 `[借用流程](eeg-management/borrow.md)`。
- 新增一個設備教學區：建一個資料夾（例如 `eye-tracker/`），
  裡面放一個 `README.md`（開啟資料夾時會自動顯示），
  再放各個 `.md` 子頁，並在本頁與資料夾的 `README.md` 加上連結。
- **注意**：GitHub 會移除 `<iframe>` 與 `<script>`，所以無法內嵌日曆，
  只能放「連結」。
