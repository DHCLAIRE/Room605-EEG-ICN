## EEG 操作手冊 / Operation Manual

**組裝 / Assembly**

底座與訊號線連接 → 轉接頭接 Headbox → Headbox 接底座（燈亮即成功）→ 連接電極帽與 bipolar channels（EOG）→ 插入軟體鎖。
Connect base & signal cables → adapter to Headbox → Headbox to base (light turns on when correct) → connect electrode cap and bipolar channels (EOG) → insert the dongle.

**記錄軟體 Curry / Recording software**

開啟 Curry → 建立新的（或載入舊的）study → 透過網路連結放大器（可能需數次）→ 選擇組態檔 → 設定記錄參數（取樣率、濾波）→ 設定記錄檔名 → 開始量測 → 開始記錄。
Launch Curry → create new (or load old) study → connect to the amplifier via network (may take a few attempts) → select the configuration file → set recording parameters (sampling rate, filters) → name the session → begin acquisition → start recording.

> 完整圖解請參考 **R605 EEG Device Instructions** 與 **20250502 R605 EEG Workshop** 投影片。
> For full illustrated steps, see the **R605 EEG Device Instructions** and **20250502 R605 EEG Workshop** slides.

## 常見問答 / Q&A

| 中文 | English |
|------|---------|
| 64 通道電極帽可以用嗎？→ R605 不適用；請洽 **R608** 進行 64 通道實驗。 | Are 64-channel caps usable? → Not in R605; contact **R608** for 64-channel experiments. |
| 耗材可用多久？→ 視庫存而定，請洽管理團隊。 | How long can we use provided consumables? → Depends on stock; ask the team. |
| 有快速檢查通道導電度的方法嗎？→ 優先檢查紅色／高阻抗通道；善用回報表追蹤訊號品質。 | Faster conductivity check? → Check red/high-impedance channels first; use the report form to track signal quality. |
| Windows 浮水印怎麼移除？→ 可能需更新授權；再出現時告知團隊。 | Remove Windows watermark? → License may need updating; tell the team if it reappears. |
| 螢幕距離／固定點要標準化嗎？→ 會標記標準距離；各實驗請自行維持一致並用畢歸位。 | Standardize screen distance/fixation? → A standard distance is marked; keep settings consistent per experiment and restore positions. |
| 系統與軟體設定要統一嗎？→ 套用預設設定；未經許可禁止變更。 | Standardize settings? → Default settings apply; changes forbidden without permission. |
